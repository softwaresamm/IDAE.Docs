La versión **1.2.30.1** de SAMM API amplía la gestión de certificados (categoría, relación con unidades/equipos, descarga masiva y guardado de válidos), suma el envío a Siigo, un endpoint de clasificación de solicitudes con IA y mejoras en autoguardado y Dashboard.

<!-- truncate -->

## Novedades

- Se agregó la columna categoría al maestro de certificados. ([SO-732](https://softwaresamm.atlassian.net/browse/SO-732))
- Se incorporó el CRUD para relacionar certificados con unidades y equipos. ([SO-733](https://softwaresamm.atlassian.net/browse/SO-733))
- Se habilitó el guardado de certificados válidos. ([SO-734](https://softwaresamm.atlassian.net/browse/SO-734))
- Se implementó el envío de información a Siigo. ([SO-741](https://softwaresamm.atlassian.net/browse/SO-741))
- Se agregó la descarga masiva de certificados. ([SO-744](https://softwaresamm.atlassian.net/browse/SO-744))
- Se habilitó la obtención de valores de parámetros desde los sistemas origen. ([SO-746](https://softwaresamm.atlassian.net/browse/SO-746))
- Se creó un endpoint para clasificar solicitudes utilizando Claude como proveedor de IA. ([SO-748](https://softwaresamm.atlassian.net/browse/SO-748))
- Se permitió el guardado de archivos uno a uno. ([SO-749](https://softwaresamm.atlassian.net/browse/SO-749))
- Se agregó un identificador para enlazar los autoguardados. ([SO-750](https://softwaresamm.atlassian.net/browse/SO-750))
- Se adicionó el alcance en el Dashboard. ([SO-767](https://softwaresamm.atlassian.net/browse/SO-767))
- Se habilitó el filtro de certificados de valor por unidad/posición seleccionada en la consulta. ([SO-774](https://softwaresamm.atlassian.net/browse/SO-774))
- Se realizaron ajustes al BloqueHome de técnicos, para ver los mismos servicios programados en la app. ([SO-778](https://softwaresamm.atlassian.net/browse/SO-778))
- Se habilitó la entrega de información de un solo servicio. ([SO-779](https://softwaresamm.atlassian.net/browse/SO-779))

## Correcciones

- Se agregaron las columnas de id_tecnico a la vista View_Ort_programacion. ([SO-762](https://softwaresamm.atlassian.net/browse/SO-762))
