La versión **7.1.17.0** de SammNew agrega el resumen de cotización, el parámetro de reportes adicionales para el Utilitario de Reporte Técnico, la gestión de tipos de archivo y documentos sugeridos, y el reporte de no disponibilidades, además de corregir la duplicación del código de programación y el listado de coordinadores, entre otros ajustes.

<!-- truncate -->

## Novedades

- Se filtran los proveedores inactivos en el campo de proveedores según el modo de uso. ([SO-609](https://softwaresamm.atlassian.net/browse/SO-609))
- Se habilitó el manejo de opciones para las cotizaciones. ([SO-745](https://softwaresamm.atlassian.net/browse/SO-745), [SO-2130](https://softwaresamm.atlassian.net/browse/SO-2130))
- Se corrigió la duplicación del código de programación al crear una visita a partir de otra. ([SO-2116](https://softwaresamm.atlassian.net/browse/SO-2116))
- Se habilitó un parámetro para controlar la visualización de reportes adicionales en el Utilitario de Reporte Técnico, y se expuso el listado de reportes disponibles para el envío de correo. ([SO-2120](https://softwaresamm.atlassian.net/browse/SO-2120), [SO-2121](https://softwaresamm.atlassian.net/browse/SO-2121))
- Se habilitó la gestión de tipos de archivo y clasificación de documentos sugeridos, con permisos para adicionar sugeridos en órdenes de trabajo finalizadas y editar información adicional en documentos cerrados. ([SO-42](https://softwaresamm.atlassian.net/browse/SO-42), [SO-43](https://softwaresamm.atlassian.net/browse/SO-43), [SO-2106](https://softwaresamm.atlassian.net/browse/SO-2106), [SO-2132](https://softwaresamm.atlassian.net/browse/SO-2132), [SO-2134](https://softwaresamm.atlassian.net/browse/SO-2134), [SO-2135](https://softwaresamm.atlassian.net/browse/SO-2135), [SO-2136](https://softwaresamm.atlassian.net/browse/SO-2136), [SO-2137](https://softwaresamm.atlassian.net/browse/SO-2137))
- Se eliminaron las opciones de alineación de texto en el editor enriquecido, corrigiendo que el teclado se ocultara al escribir en el campo de trabajos. ([SO-2173](https://softwaresamm.atlassian.net/browse/SO-2173), [SO-2141](https://softwaresamm.atlassian.net/browse/SO-2141), [SO-626](https://softwaresamm.atlassian.net/browse/SO-626))
- Se replicó la firma adjunta en la solicitud. ([SO-2094](https://softwaresamm.atlassian.net/browse/SO-2094))
- Se permitió configurar la obligatoriedad, visibilidad y autoselección de la preliquidación al cerrar órdenes de trabajo. ([SO-2079](https://softwaresamm.atlassian.net/browse/SO-2079))
- Se agregó el campo Usuario Asignado al formulario de cierre masivo de órdenes de trabajo. ([SO-2144](https://softwaresamm.atlassian.net/browse/SO-2144))
- Se habilitó el reporte de no disponibilidades. ([SO-2145](https://softwaresamm.atlassian.net/browse/SO-2145), [SO-2180](https://softwaresamm.atlassian.net/browse/SO-2180), [SO-2181](https://softwaresamm.atlassian.net/browse/SO-2181), [SO-2182](https://softwaresamm.atlassian.net/browse/SO-2182))

## Correcciones

- Se corrigió la visualización de existencias cuando tienen el caracter "comilla sencilla". ([SO-706](https://softwaresamm.atlassian.net/browse/SO-706))
- Se habilitó la edición de listas de chequeo desde el reporte técnico. ([SO-2095](https://softwaresamm.atlassian.net/browse/SO-2095))
- Se permitió guardar el estado del equipo desde el reporte técnico. ([SO-2096](https://softwaresamm.atlassian.net/browse/SO-2096))
- Se corrigió el error al guardar temparios con cantidad planeada en cero. ([SO-2117](https://softwaresamm.atlassian.net/browse/SO-2117))
- Se corrigió el listado de coordinadores para excluir usuarios no habilitados en contratos. ([SO-2162](https://softwaresamm.atlassian.net/browse/SO-2162))
