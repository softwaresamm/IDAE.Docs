La versión **1.2.34.5** de SAMM API incorpora mejoras en licenciamiento, recursos, permisos y captura de fotos, además de una corrección en el envío de servicios.

<!-- truncate -->

## Novedades

- Se corrigió la duplicación de plantillas de documentos: ya no se cierra la plataforma al duplicar y ahora se replican correctamente las secciones y atributos. ([SO-2231](https://softwaresamm.atlassian.net/browse/SO-2231), [SO-660](https://softwaresamm.atlassian.net/browse/SO-660))
- Se incorporó en los parámetros de licencia la capacidad de almacenamiento contratada y el porcentaje de advertencia, mostrando un mensaje informativo cuando el consumo se acerque o supere el límite contratado. ([SO-2228](https://softwaresamm.atlassian.net/browse/SO-2228), [SO-2227](https://softwaresamm.atlassian.net/browse/SO-2227))
- Se agregó un campo de observaciones y se habilitó el filtro de clasificación según el tipo de documento en repuestos sugeridos. ([SO-2224](https://softwaresamm.atlassian.net/browse/SO-2224), [SO-2223](https://softwaresamm.atlassian.net/browse/SO-2223))
- Se incorporó la funcionalidad para migrar recursos de SAMM Web a SammNew. ([SO-2212](https://softwaresamm.atlassian.net/browse/SO-2212), [SO-2210](https://softwaresamm.atlassian.net/browse/SO-2210))
- Se agregaron los formularios para llamar, actualizar y guardar los cambios de los recursos. ([SO-2207](https://softwaresamm.atlassian.net/browse/SO-2207), [SO-2206](https://softwaresamm.atlassian.net/browse/SO-2206), [SO-2205](https://softwaresamm.atlassian.net/browse/SO-2205), [SO-1990](https://softwaresamm.atlassian.net/browse/SO-1990))
- Se agregó una marca de fecha y hora (timestamp) sobre las fotos tomadas directamente desde la cámara. ([SO-2202](https://softwaresamm.atlassian.net/browse/SO-2202))
- Se restringió por permisos el acceso al botón de reportes Power BI. ([SO-2196](https://softwaresamm.atlassian.net/browse/SO-2196), [SO-2184](https://softwaresamm.atlassian.net/browse/SO-2184))
- Se corrigió la codificación de caracteres especiales en las descripciones de fotos. ([SO-2186](https://softwaresamm.atlassian.net/browse/SO-2186))
- Se filtran los atributos visibles en la app según la columna "mostrarapi" al crear una orden de trabajo (OT). ([SO-2150](https://softwaresamm.atlassian.net/browse/SO-2150))
- Se valida el diligenciamiento de la lista de chequeo antes de permitir reportar un servicio. ([SO-2149](https://softwaresamm.atlassian.net/browse/SO-2149))
- Se incorporó la lectura de la columna "defecto" de la tabla de columnas para la creación de documentos. ([SO-2139](https://softwaresamm.atlassian.net/browse/SO-2139))
- Se restringió el permiso del perfil de cliente para que no pueda imprimir PDF. ([SO-602](https://softwaresamm.atlassian.net/browse/SO-602))
- Se corrigió el guardado de la asociación entre usuario y bodega, que no se almacenaba correctamente. ([SO-434](https://softwaresamm.atlassian.net/browse/SO-434))

## Correcciones

- Se corrigió la pérdida de imágenes al enviar dos servicios consecutivos desde la plataforma. ([SO-2220](https://softwaresamm.atlassian.net/browse/SO-2220))
