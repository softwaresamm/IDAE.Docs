La versión **2.3.4.6** de App Técnicos mejora la gestión de equipos, checklists y el envío de solicitudes, además de corregir errores de navegación y de acceso en iOS.

<!-- truncate -->

## Novedades

- Se agregó un identificador en el formulario de creación de servicios, dentro de gestión de equipos, para el manejo de imagenes. ([SO-766](https://softwaresamm.atlassian.net/browse/SO-766))
- Se mejoró el manejo de la solicitud de permisos del sistema en Android. ([SO-2114](https://softwaresamm.atlassian.net/browse/SO-2114))
- Se elimina funcionalidad de texto enriquecido. ([SO-626](https://softwaresamm.atlassian.net/browse/SO-626))
- Se habilitó la apertura de enlaces dentro de los campos de solo lectura de la aplicación. ([SO-2078](https://softwaresamm.atlassian.net/browse/SO-2078))
- Se migró el consumo del servicio a REST, quitando el uso de páginas .aspx desde SAMM API v1.2.30.1. ([SO-2080](https://softwaresamm.atlassian.net/browse/SO-2080))
- Se habilitó la descarga de las peticiones JSON que quedan pendientes en la cola de envío. ([SO-2082](https://softwaresamm.atlassian.net/browse/SO-2082))
- Se garantizó el envío completo de la lista de chequeo. ([SO-2107](https://softwaresamm.atlassian.net/browse/SO-2107))
- Se retiró el sonido del obturador al capturar fotografías desde la cámara de la aplicación. ([SO-735](https://softwaresamm.atlassian.net/browse/SO-735))
- Se corrigió el diligenciamiento independiente de atributos que comparten el mismo nombre dentro de las listas de chequeo. ([SO-776](https://softwaresamm.atlassian.net/browse/SO-776))
- Se habilitó la búsqueda de equipos por número de serie sin necesidad de estar dentro de CMM. ([SO-1969](https://softwaresamm.atlassian.net/browse/SO-1969))

## Correcciones

- Se corrigió el error de acceso en la app iOS cuando la URL configurada utiliza protocolo HTTP. ([SO-694](https://softwaresamm.atlassian.net/browse/SO-694))
- Se evitó el consumo innecesario del servicio de guardado de checklist de inicio cuando no hay preoperacionales configurados. ([SO-764](https://softwaresamm.atlassian.net/browse/SO-764))
- Se corrigió la navegación al visualizar imágenes desde la previsualización. ([SO-770](https://softwaresamm.atlassian.net/browse/SO-770))
- Se ajustó la navegación entre pantallas durante la edición de órdenes de trabajo. ([SO-771](https://softwaresamm.atlassian.net/browse/SO-771))

## Versiones requeridas

| Componente | Versión mínima |
| ---------- | -------------- |
| SAMM API   | 1.2.32.0       |
| SAMM New (SN) | 7.1.16.0    |
| Utilitario Reporte Técnico (URT) | 4.0.1 |

> SN v7.1.16.0 y URT v4.0.1 son versiones recomendadas para aprovechar completamente las mejoras de este release.
