La versión **1.2.33.1** de SAMM API incorpora el filtrado jerárquico de sucursales, el envío de varios formatos de reporte y reportes adicionales, la gestión de tipos de archivo y documentos sugeridos, la sección de estado del equipo y el reporte de no disponibilidades, y corrige el envío de correo sin adjunto y la respuesta de checklist por equipo.

<!-- truncate -->

## Novedades

- Se habilitó el filtrado jerárquico de sucursales (padre e hijas) en el servicio de campos, utilizado por la descarga masiva. ([SO-2142](https://softwaresamm.atlassian.net/browse/SO-2142), [SO-2143](https://softwaresamm.atlassian.net/browse/SO-2143))
- Se filtran los proveedores inactivos en el campo de proveedores según el modo de uso. ([SO-609](https://softwaresamm.atlassian.net/browse/SO-609))
- Se adicionó un índice para PK_docNum y se ajustó la máscara en la base de datos básica. ([SO-2111](https://softwaresamm.atlassian.net/browse/SO-2111))
- Se habilitó el envío de varios formatos de reporte (RM y RA) y el procesamiento de reportes adicionales seleccionados dentro del JSON de reporte, exponiendo el listado de reportes disponibles. ([SO-518](https://softwaresamm.atlassian.net/browse/SO-518), [SO-2119](https://softwaresamm.atlassian.net/browse/SO-2119), [SO-2120](https://softwaresamm.atlassian.net/browse/SO-2120), [SO-2121](https://softwaresamm.atlassian.net/browse/SO-2121), [SO-2122](https://softwaresamm.atlassian.net/browse/SO-2122), [SO-2152](https://softwaresamm.atlassian.net/browse/SO-2152))
- Se crearon las tablas para el manejo de opciones de cotización. ([SO-2130](https://softwaresamm.atlassian.net/browse/SO-2130))
- Se habilitó la gestión de tipos de archivo y clasificación de documentos sugeridos, con permisos para adicionar sugeridos en órdenes de trabajo finalizadas y editar información adicional en documentos cerrados. ([SO-42](https://softwaresamm.atlassian.net/browse/SO-42), [SO-43](https://softwaresamm.atlassian.net/browse/SO-43), [SO-2106](https://softwaresamm.atlassian.net/browse/SO-2106), [SO-2132](https://softwaresamm.atlassian.net/browse/SO-2132), [SO-2134](https://softwaresamm.atlassian.net/browse/SO-2134), [SO-2135](https://softwaresamm.atlassian.net/browse/SO-2135), [SO-2136](https://softwaresamm.atlassian.net/browse/SO-2136), [SO-2137](https://softwaresamm.atlassian.net/browse/SO-2137))
- Se corrigió la asignación de repuestos en la bandeja de programación de órdenes, evitando que fuera necesario actualizarla dos veces. ([SO-2155](https://softwaresamm.atlassian.net/browse/SO-2155))
- Se agregó la sección de cambio de estado del equipo. ([SO-688](https://softwaresamm.atlassian.net/browse/SO-688), [SO-2153](https://softwaresamm.atlassian.net/browse/SO-2153), [SO-2175](https://softwaresamm.atlassian.net/browse/SO-2175))
- Se habilitó el reporte de no disponibilidades. ([SO-2145](https://softwaresamm.atlassian.net/browse/SO-2145), [SO-2180](https://softwaresamm.atlassian.net/browse/SO-2180), [SO-2181](https://softwaresamm.atlassian.net/browse/SO-2181), [SO-2182](https://softwaresamm.atlassian.net/browse/SO-2182))

## Correcciones

- Se corrigió el envío de correo sin adjunto al reportar con la regla de envío "1-reporteTecnico" en el dinámico. ([SO-369](https://softwaresamm.atlassian.net/browse/SO-369))
- Se corrigió la respuesta del checklist por equipo para incluir los campos de tipo lista. ([SO-2110](https://softwaresamm.atlassian.net/browse/SO-2110))
