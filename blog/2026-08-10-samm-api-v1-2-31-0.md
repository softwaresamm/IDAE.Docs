La versión **1.2.31.0** de SAMM API fortalece la sincronización y validación de licencias durante la autenticación, mejora el endpoint de actualización de base de datos y suma ajustes al dashboard de certificados.

<!-- truncate -->

## Novedades

- Se fortaleció la sincronización y validación de licencias durante la autenticación en SAMM: un nuevo servicio (`GET /api/lic/obtenerSwl`) consulta el SWL de una licencia activa y reemplaza la página `keys.aspx`. Los flujos de login de SAMM API, SAMM New e `inbyser` ahora sincronizan automáticamente los parámetros de la licencia (usuarios, equipos, sucursales, módulos, fechas) antes de autenticar, y muestran mensajes claros y sin datos sensibles cuando la licencia no puede validarse. ([SO-675](https://softwaresamm.atlassian.net/browse/SO-675))
- Se actualizó el endpoint de actualización de base de datos para permitir elegir entre actualizar solo la base básica o incluir también los scripts personalizados. ([SO-2089](https://softwaresamm.atlassian.net/browse/SO-2089))
- Se agregó la columna Unidad de posición en la tabla del dashboard, el estado "próximo a vencer" ahora se muestra cuando faltan 30 días para el vencimiento, se evitó registrar fechas futuras en la fecha de certificado y se ajustaron los permisos de eliminación por perfil. ([SO-2091](https://softwaresamm.atlassian.net/browse/SO-2091))

## Correcciones

- Se corrigió la obtención de la ubicación del archivo `web.config` al activar una licencia. ([SO-747](https://softwaresamm.atlassian.net/browse/SO-747))
