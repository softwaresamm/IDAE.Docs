La versión **1.2.35.3** de SAMM API incorpora el registro de actividades sin OT ni programación, el registro de gastos desde el reporte de servicio, la validación de compatibilidad entre la base de datos y la capa de datos, y correcciones en movimientos de alquiler y en la creación de gastos.

<!-- truncate -->

## Novedades

- Se incorporó la comparación de versiones entre la base de datos y la capa de datos. ([SO-2226](https://softwaresamm.atlassian.net/browse/SO-2226), [SO-2200](https://softwaresamm.atlassian.net/browse/SO-2200))
- Se agregó un permiso para controlar la visualización y configuración de opciones. ([SO-2234](https://softwaresamm.atlassian.net/browse/SO-2234), [SO-2197](https://softwaresamm.atlassian.net/browse/SO-2197))
- Se agregó la configuración para que el asesor vea solo sus cotizaciones y el parámetro `CotSoloMisCotizaciones`. ([SO-2242](https://softwaresamm.atlassian.net/browse/SO-2242), [SO-2243](https://softwaresamm.atlassian.net/browse/SO-2243))
- Ahora se identifica el tipo de dato de la firma en lugar de basarse en el nombre de la firma. ([SO-2146](https://softwaresamm.atlassian.net/browse/SO-2146))
- Se agregó el botón de unificación de departamentos de solicitud en la barra de herramientas. ([SO-2246](https://softwaresamm.atlassian.net/browse/SO-2246))
- Se permitió registrar reportes de actividades sin OT ni programación. ([SO-2248](https://softwaresamm.atlassian.net/browse/SO-2248), [SO-2247](https://softwaresamm.atlassian.net/browse/SO-2247))
- Se agregó una columna obligatoria a la evaluación de documentos y la encuesta solo se exige para firmar el reporte cuando es obligatoria. ([SO-2249](https://softwaresamm.atlassian.net/browse/SO-2249), [SO-2251](https://softwaresamm.atlassian.net/browse/SO-2251))
- Se permitió registrar gastos desde la pantalla de reportar servicio. ([SO-2256](https://softwaresamm.atlassian.net/browse/SO-2256))
- Se adicionó el tab "Detalle Gasto" al documento de gasto en la base de datos básica. ([SO-2254](https://softwaresamm.atlassian.net/browse/SO-2254))
- Se permitieron decimales con punto en el registro del detalle de gastos. ([SO-2240](https://softwaresamm.atlassian.net/browse/SO-2240))

## Correcciones

- Se corrigió el reseteo indebido de fechas al cancelar movimientos (RE) de alquiler. ([SO-2236](https://softwaresamm.atlassian.net/browse/SO-2236))
- Se corrigió la creación del gasto registrado desde el reporte técnico. ([SO-2255](https://softwaresamm.atlassian.net/browse/SO-2255))

## Versiones requeridas

| ------------- | -------------- |

| CAPADATOS     | 2.1.22.1       |
| BASE DE DATOS | C2.1.22.1      |
| SAMM CORE     | 2.0.30.1       |
